Depois de adicionar este arquivo ao seu projeto, você precisa fazer uma pequena configuração no seu repositório do GitHub:

Envie o arquivo: Adicione este novo arquivo (deploy.yml) ao seu repositório e envie as alterações para o GitHub (git commit e git push).

Vá para as Configurações: No seu repositório no site do GitHub, vá para Settings > Pages.

Mude a Fonte de Publicação: Na seção "Build and deployment", mude a opção Source de "Deploy from a branch" para "GitHub Actions".
